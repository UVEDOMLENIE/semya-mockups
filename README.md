# «СемьЯ» — макеты, версия 2

Сайт: https://uvedomlenie.github.io/semya-mockups/

- `index.html` — главная-история: приветствие, идея в трёх картинках, три варианта в окошках-телефонах, три имени, план из шести шагов А–Е, документы, выбор варианта.
- `1-ee-videnie.html` — по выкройке заказчицы: полная анкета, 5 тестов, подписка, карточки-открытки.
- `2-konservativnoe.html` — спокойный: 5 полей анкеты, 8 вопросов о семье, портрет, карточки «где совпали / о чём поговорить».
- `3-ultra.html` — для смелых: «Хватит свайпать. Пора жениться».
- `docs/` — три документа: как мы поняли идею, взгляд со стороны, похожие сервисы в мире.
- `app.js` — общий движок: тест, портрет, подбор (больше 50%, до 7 человек), кнопка «Замечание» (одна копилка на все страницы, выгрузка в Word).
- `v1/` — первая версия, сохранена как есть (git-тег `v1`).

Люди в макетах выдуманные, ничего никуда не отправляется.
