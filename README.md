# «СемьЯ» — макеты

Сайт: https://uvedomlenie.github.io/semya-mockups/

Версия 3: три разных продукта, а не три оформления одного.

- `1-ee-videnie.html` + `v1.js` — её версия, точно по её четырём документам (анкета, 5 тестов, свод с биоритмами и гороскопом, карточка по образцу №4).
- `2-odin-v-den.html` + `v2.js` — «Один человек в день»: собеседование-переписка, портрет-письмо, один человек в день, три вопроса «на берегу», переписка, обмен контактами по согласию.
- `3-sem-dney.html` + `v3.js` — «Семь дней вслепую»: неделя семейных ситуаций с одним человеком, имя и лицо на седьмой день.
- `people.js` — выдуманные люди и 8 вопросов о семье; `notes.js` — кнопка «Замечание» (Поделиться / Скопировать / Word).
- `img/` — картинки экранов для главной; `docs/` — документы.
- Состояние каждого макета хранится в браузере; `?reset=1` — начать заново.

Старые версии: `v1/` (тег v1), `v2/` (тег v2). ТЗ на эту версию — `АУДИТ_и_ТЗ_от_Fable.md` в папке проекта.
