# «СемьЯ» — три макета

Кликабельные макеты первой версии сервиса знакомств «для создания семьи, а не для свиданий». Все люди выдуманные, ничего никуда не отправляется.

- `1-ee-videnie.html` — вариант заказчицы: полная анкета, 5 тестов, подписка, карточка по её макету.
- `2-konservativnoe.html` — спокойный: короткая анкета, 8 вопросов о детях, деньгах, родителях и ссорах, семейный портрет, до 7 карточек.
- `3-ultra.html` — кричащий: «Хватит свайпать. Пора жениться».
- `app.js` — общий движок (тест, портрет, подбор больше 50%, до 7 человек, кнопка «Замечание»).

Открыть: `index.html`.
